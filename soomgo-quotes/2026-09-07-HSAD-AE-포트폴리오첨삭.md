## 판단

### 고객이 실제로 묻고 있는 것
"HSAD AE"라는 **특정 회사 + 특정 직무**를 못 박아서 물었다. 이건 "포폴 첨삭 되나요"가 아니라 **"내 업계를 아는 사람인가"** 를 검증하는 질문이다.

### 결론: 완전 거절 ❌ / 완전 수락 ❌ / **솔직 고지 후 범위 축소 수락 ✅**

| 선택지 | 평가 |
|---|---|
| "네, 경험 있습니다" | ❌ 첫 세션에서 드러남. 대행사 포폴은 캠페인 크리에이티브 심사가 들어가는데 커버 불가 |
| 무응답 / 거절 | ❌ 구조·성과 서술·JD 연결은 실제로 해줄 수 있는데 통째로 버리는 셈 |
| **못 하는 것 먼저 → 할 수 있는 것 → 선택권 이전** | ✅ 채택 |

### 경계선

| 내 영역 | 현직 AE 영역 |
|---|---|
| 포폴 전체 구조·프로젝트 배치 순서 | 캠페인 아이디어가 대행사 눈에 먹히는가 |
| 프로젝트 1건당 서술 구조 (상황·역할·실행·성과) | 카피·비주얼 완성도 |
| 성과 정량화 | 업계 레퍼런스 대비 수준 |
| HSAD 공고(JD) 기준 우선순위 재배치 | 대행사 내부 전형 관행 |
| 포폴–자소서–면접 일관성 | |

한 줄 요약: **"읽히는 포폴로 만드는 것"은 내 영역, "광고 크리에이티브 자체의 완성도 판단"은 내 영역이 아니다.**

### 근거로 쓸 실적
- 마케팅 직무 포트폴리오 첨삭
- 개발 프로젝트 포트폴리오 첨삭
- 총 13년 경력 중 이직 2회, 현재 직장 안착까지의 서류·면접 실경험

→ 직무명이 아니라 **"직무가 달라도 동일하게 적용되는 항목"** 이라는 프레임으로 제시. 마케팅 실적은 AE와 인접 영역이라 설득력이 있다.
