## ★ 이 건의 핵심 — 장문 견적이 안 읽혔다

진행 방식은 **09-02 메시지에 이미 다 들어 있었다.** 그런데 고객은 5일 뒤 간편답변 버튼으로 같은 걸 물었다.

**진단**: 숨고 채팅은 긴 메시지를 `전체보기`로 접는다. 접힌 뒤쪽 내용은 전달되지 않는다.

**증거 2가지**
1. 메시지 끝의 **질문 4개**(지원 기업·직무 / 서류 유무 / 문항 수·기한 / 인터뷰 방식)에 **하나도 답이 오지 않았다**
2. 고객이 직접 타이핑하지 않고 **간편답변 버튼**을 눌렀다 → 읽고 답하는 비용을 최소화하려는 상태

**대응**: 여기서 다시 길게 쓰면 같은 일이 반복된다. **3단계 + 질문 1개**로 끊는다.

### 질문을 4개 → 1개로 줄인 근거

| 원래 질문 | 지금 필요한가 |
|---|---|
| 지원 기업·직무 또는 공고 | 서류 받은 뒤에 물어도 됨 |
| **현재 작성된 이력서·자소서 유무** | ✅ **이 답 하나로 1안/2안이 갈린다** |
| 자소서 문항 수와 제출 기한 | 서류에 대부분 드러남 |
| 인터뷰 방식 선호도 | 2안 이상으로 갈 때만 필요 |

모바일에서 질문 4개는 "나중에 답해야지"가 되고, 그 나중은 오지 않는다.

## ★★ 재진단 — 빠진 건 "설명"이 아니라 "선택 기준"이었다

1~3안을 기준으로 다시 답장하기로 하면서 원래 견적을 다시 보니, 진짜 공백이 드러났다.

원래 견적에는 세 안의 **설명**이 모두 있었다. 없는 것은 **"누가 어떤 안을 골라야 하는가"** 였다.

| 원래 견적에 있던 것 | 없던 것 |
|---|---|
| 1안 = 문항별 핵심 메시지와 구성·흐름·표현 검토 후 첨삭 | 이걸 **누가** 골라야 하는지 |
| 2안 = 추가 질의응답으로 근거 보완, 스토리라인부터 재구성 | 1안과 2안 사이에서 **뭘 보고** 판단하는지 |
| 3안 = 실시간 인터뷰로 발굴 후 전체 완성 | 3안까지 가야 하는 **상태**가 어떤 건지 |

**"진행 방식은 어떻게 되나요?"의 실제 의미 = "그래서 저는 뭘 하면 되나요?"**

공급자 언어(첨삭 / 재구성 / 발굴)로만 쓰여 있으면 고객은 자기 상황에 대입할 수 없다. 그래서 안 설명을 반복하지 않고 **"→ 이럴 때 고르세요" 한 줄씩**을 새로 붙인다.

| 안 | 선택 기준 (새로 추가) |
|---|---|
| 1안 | 자소서가 **이미 있고 다듬기만** 필요할 때 |
| 2안 | 초안은 있는데 **내용이 얇거나 방향을 바꿔야** 할 때 |
| 3안 | **뭘 써야 할지부터 막막**할 때 |

원칙 10(짧게)과 충돌하는 것처럼 보이지만, 세 안을 다시 풀어쓰는 대신 선택 기준만 얹었으므로 **원래 견적보다 짧다.** 질문도 여전히 1개다.

## 발송 문안

```
안녕하세요 성준님! 세 안 모두 진행 흐름은 같습니다 :)

자료 전달 → 방향 잡기 → 결과물 전달 (일정 협의 가능)

차이는 가운데 "방향 잡기"를 어떻게 채우느냐입니다.

1안 · 자소서 서면 첨삭
 → 자소서가 이미 있고 다듬기만 필요하실 때
 보내주신 내용 안에서 문항별 메시지와 구성·흐름을 정리

2안 · 서면 인터뷰 + 재구성
 → 초안은 있는데 내용이 얇거나 방향을 바꿔야 할 때
 제가 질문지를 드리고, 답변으로 근거를 채워 다시 구성

3안 · 심층 인터뷰 + 재구성
 → 뭘 써야 할지부터 막막하실 때
 실시간 대화로 경험을 끌어내 전체를 새로 구성

보내드린 견적 8만원은 1안 기준이고,
2·3안은 투입이 달라 금액이 올라갑니다.

지금 작성해두신 자소서가 있으실까요?
그것만 알려주시면 어떤 안이 맞는지 바로 정리해드릴게요!
```

**설계**
- `→` 줄만 새 정보. 나머지는 이미 보낸 내용의 압축
- 소요일을 "일정 협의 가능"으로 처리해 **빈칸을 남기지 않음** (요청서의 "협의 가능해요"와도 일치)
- 8만원 = 1안 기준 한 줄로 범위 고정 (원칙 6)
- 질문 1개 유지 (원칙 9) — 자소서 유무 하나로 1안/2안이 갈린다

## 진행 시 미리 볼 것 — 학력·연령 조합

요청서에 **전문대 졸업/졸업예정 + 30대 + 대기업 지원**이 함께 있다. 대기업 서류에서 이 조합은 반드시 설명이 필요한 지점이 되고, 자소서 전략의 중심이 될 가능성이 높다.

**경력 유무에 따라 전략이 완전히 갈린다.**

| 경우 | 방향 |
|---|---|
| 실무 경력 있음 (재직 중 진학 등) | 학력이 아니라 **경력 연차와 성과**를 전면에. 전문대는 설명 대상이 아니라 배경 |
| 경력 없음 / 신입 | 공백기와 학력을 한 문장으로 정리하고 **직무 관련 준비 밀도**로 승부 |

**지금 묻지 않는다.** 견적 단계에서 학력을 건드리면 약점을 지적당한 느낌을 준다. 서류를 받은 뒤 자연스럽게 확인한다.
