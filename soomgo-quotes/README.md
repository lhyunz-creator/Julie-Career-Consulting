# 숨고 견적·상담 응대 누적 기록

문의가 올 때마다 **판단 근거와 실제 보낸 문안**을 남겨서, 다음 견적에서 같은 고민을 반복하지 않기 위한 폴더입니다.

---

## Ⅰ. 서비스 범위 — 받을 수 있는 것 / 없는 것

문의가 오면 먼저 이 표에 대입합니다. 회색지대면 "솔직하게 말하고 범위를 좁혀서" 받습니다.

### ✅ 직무와 무관하게 항상 제공 가능 (핵심 자산)

| 영역 | 내용 |
|---|---|
| 문서 구조 | 포폴/이력서 전체 구성 — 무엇을 몇 개, 어떤 순서로 |
| 항목별 서술 | 상황 → 본인 역할 → 실행 → 성과가 3초 안에 읽히는 형태 |
| 성과 정량화 | 숫자 없는 프로젝트에서 숫자 뽑아내기 |
| JD 연결 | 공고 문구를 기준으로 앞에 둘 것 / 뺄 것 판단 |
| 일관성 | 포폴 – 자소서 – 면접 답변 정합성 |
| 면접 대응 | 예상 질문 도출, 답변 구조화 |

근거: 총 13년 경력 · 이직 2회 · 현재 직장 안착까지 다수의 서류/면접 실경험.

### ⚠️ 조건부 (선을 긋고 받기)

| 상황 | 응대 |
|---|---|
| 경험 없는 직무의 포폴 | 위 ✅ 영역만 제공한다고 명시하고 받기 |
| 업계 내부 기준이 필요한 심사 | 못 한다고 먼저 말하고, 나머지 범위만 제안 |

### ❌ 받지 않는 것

| 영역 | 이유 |
|---|---|
| 크리에이티브 결과물의 업계 눈높이 평가 (광고 카피·캠페인 아이디어 등) | 현직자 영역. 첫 세션에서 바로 드러남 |
| 특정 기업 내부 전형 정보 | 확인 불가 |
| 대필 (본인 대신 작성) | 서비스 성격 아님 |

### 가격 구간 (2026-09 기준)

| 구성 | 금액 | 핵심 차별점 |
|---|---|---|
| 첨삭 단독 | 8만원 | 서면 인터뷰 **없음**. 기존 서류 내용 기준으로만 작업. "표준 서류" 산출 |
| 서면 컨설팅 | 18만원 | 서면 질문지 + 공고 분석 + 소재 선별 + **기업별 강조 포인트·스토리라인 설계** |
| 인터뷰 포함 | 상위 | (2안) |

**8만원과 18만원을 가르는 것은 "서면 인터뷰 유무"와 "기업별 맞춤 여부"** 두 가지다. 하위 안 설명에서 이 두 단어가 새어나가지 않게 한다.

## Ⅱ. 응대 원칙 (누적)

1. **"경험 있냐"는 질문에 없는 경험을 있다고 하지 않는다.** 첫 세션에서 드러나고, 그때 잃는 게 훨씬 크다.
2. **거절 대신 범위 축소.** "못 합니다"가 아니라 "이건 못 하고, 이건 확실히 합니다"로 답한다.
3. **못 하는 걸 먼저 말한다.** 순서가 중요하다. 못 하는 것 → 할 수 있는 것 → 선택은 고객이. 이 순서가 신뢰를 만든다.
4. **선택권을 고객에게 넘기고 끝낸다.** 설득으로 닫지 않는다. "이 범위로 괜찮으시면"까지가 내 몫.
5. **48시간 미접속 건은 가볍게 한 번 더 톡.** 상담 여부와 무관하게 도와줄 수 있다는 톤으로. (2026-09-06 건에서 실제로 읽고 답장 옴)
6. **가격을 확인해주는 답변에는 반드시 범위를 붙인다.** "네 8만원 맞습니다"로 끝내지 않는다. 포함 항목 · 수정 횟수 · 포함되지 않는 것까지 한 번에. 금액만 확정하면 범위는 고객이 정하게 된다.
7. **하위 안을 설명할 때 상위 안의 핵심 단어를 쓰지 않는다.** 상위 안이 "스토리라인 설계"로 팔리고 있다면 하위 안 설명에 "스토리 짜서"를 쓰는 순간 두 안의 차이가 사라진다. 가격 차이의 근거는 **투입 방식의 차이**(예: 서면 인터뷰 유무)로 댄다.
8. **"완성해드려요"를 쓰지 않는다.** 대필 뉘앙스이고 결과물 책임이 무한대로 열린다. "정리해드려요"가 안전하다.
