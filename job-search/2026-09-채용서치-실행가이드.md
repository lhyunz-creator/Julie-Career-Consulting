# Ⅵ. 지원서 강조 포인트

만료 공고들의 JD에서 반복 확인된 패턴이라 시점과 무관하게 유효합니다.

- **정량화** — 월 처리 오더 건수, 정산 규모, 오류율·리드타임 개선 폭
- **시스템** — **SAP / ERP / CRM 경험은 반드시 명시.** ①번 JD 대다수가 SAP를 직접 요건에 겁니다
- **여신·재고 판단** — credit check / inventory check가 DKSH·KISTEMP류 JD에 반복 등장
- **협업 축** — 영업 ↔ 물류·SCM ↔ 재무 조율 경험 = "기업 고객 운영" 역량의 직접 증거
- **영어** — 외국계 ①②번 다수가 요건. 실제 사용 맥락(메일·미팅·리포트)으로 구체화
